bench: add a diamond-chain throughput benchmark

Each rule in the chain references its predecessor twice, so the top rule
touches the base rule 2^depth times without memoisation and only depth
times with it. The program prints a checksum so the work cannot be
optimised away; wall time is measured from outside with `time`.

Measured on this machine (500 queries, depth 12, checksum 2048000 in
both runs):

- with the rule cache:    ~128 ms
- with the cache bypassed: ~833 ms

about 6.5x, purely from memoisation.
