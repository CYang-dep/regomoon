perf: memoise argless rule evaluation within a query

Rules are pure: they read only the module, data and input. A result computed
once is therefore valid for every reference inside the same query, which
turns a diamond-shaped rule graph from once-per-path into once-per-query.

Errors stay uncached, so cyclic definitions still hit the recursion limit;
`with` builds a child environment with fresh maps, so an overridden input
can never pollute the outer cache.
